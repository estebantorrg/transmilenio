# MiTrasto

Rutas, estaciones y buses en vivo de TransMilenio y el SITP: **[mitrasto.app](https://mitrasto.app)**.

Este repositorio solo existe para que las versiones anteriores de la app para Android encuentren su actualización. Las versiones nuevas se publican en **[mitrasto-releases](https://github.com/estebantorrg/mitrasto-releases/releases/latest)**, y la forma fácil de instalar la app es **[mitrasto.app/app](https://mitrasto.app/app/)**.
